## Selected project — DeltaGrid

[DeltaGrid](https://github.com/tushar-rawat-22/Delta_Grid) is my main systems project: a single-user quantitative research platform built around falsification rather than profitability claims.

The project combines causal market-data handling, deterministic research execution, explicit cost modelling, immutable evidence, independent replay/verification, staged research governance, and strict separation between software capability and trading authority.

The research record is intentionally visible even when the answer is negative. DeltaGrid currently claims **no validated profitable strategy and no selected candidate**; paper trading, live trading, credentials, orders, and capital deployment remain closed. That boundary is part of the engineering, not a disclaimer added afterward.

Current work is extending the project with a read-only public observer and a separately isolated founder security boundary while keeping the quantitative core authoritative.
